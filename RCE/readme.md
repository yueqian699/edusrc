命令执行漏洞（Command Execution），也叫远程代码执行漏洞（Remote Code Execution），是指在应用程序或软件中存在的一种安全漏洞，允许攻击者通过操纵程序输入来执行恶意系统命令的情况。
这种漏洞通常源于程序未正确验证或过滤用户输入，导致攻击者能够利用构造特定的输入，使得程序在执行时执行了攻击者指定的系统命令，从而获取未授权的访问权限和执行任意命令操作。
由于这类漏洞危害极大，也被简称之为RCE漏洞。
